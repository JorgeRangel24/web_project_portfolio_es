# Portafolio personal — Jorge Rangel

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un portafolio web personal como parte del Sprint 4 del programa de Desarrollo Web de TripleTen.

Su objetivo es presentar mi perfil profesional como desarrollador web, mostrar mis habilidades y herramientas tecnológicas, compartir mis proyectos destacados y proporcionar diferentes medios de contacto.

El sitio cuenta con un diseño responsivo basado en un prototipo de Figma, adaptado a dispositivos móviles, tablets y computadoras.

## Funcionalidades

- Presentación personal y profesional.
- Visualización de habilidades y herramientas tecnológicas.
- Tarjetas de proyectos destacados.
- Enlaces a repositorios de GitHub y demostraciones en vivo.
- Sección de contacto y redes sociales.
- Diseño adaptable a diferentes resoluciones de pantalla.
- Estados interactivos para enlaces y navegación mediante teclado.

## Tecnologías y técnicas utilizadas

- HTML5 semántico.
- CSS3.
- Metodología BEM.
- Flexbox.
- CSS Grid.
- Media queries.
- Posicionamiento relativo y absoluto.
- Variables CSS.
- Pseudoclases y pseudoelementos.
- Transiciones y degradados CSS.
- Tipografías personalizadas: Open Sans y Archivo Black.
- Figma.
- Git y GitHub.
- Visual Studio Code.
